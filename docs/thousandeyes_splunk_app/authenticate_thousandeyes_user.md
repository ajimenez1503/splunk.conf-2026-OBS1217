# Authenticate the ThousandEyes User

To start ingest ThousandEyes data, first you need to authenticate your ThousandEyes user in the Splunk App

- Open `Cisco ThousandEyes App for Splunk`
- Navigate to `Configuration` -> `ThousandEyes User`
- Click `Add ThousandEyes User`
- Click `Authorize`
- Enter your ThousandEyes username and password and click `Login`
- On authorization page, click `Confirm`
- You will see the following message:

    ![TE integrated successfully](../img/thousandeyes_splunk_app/splunk_te_app_integrated.png)

- Once you are back in the Splunk app, click `Add`
- You should your ThousandEyes user in the list now

![add user](../img/thousandeyes_splunk_app/add_user.png)
